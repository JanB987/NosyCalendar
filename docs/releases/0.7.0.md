First public release of NosyCalendar for Obsidian Bases.

- Day, Week, Month and Year views with ISO week indicators.
- Configurable date roles, overdue rolling, conditional fills, drag rescheduling and endpoint resizing.
- Theme-aware styling with optional Style Settings controls.

Requires Obsidian 1.10.0+ and Bases. Download `main.js`, `manifest.json` and `styles.css` into `.obsidian/plugins/nosy-calendar/`; include `THIRD-PARTY-NOTICES.txt` for the complete manual package. Full license notices are also embedded in `main.js`.

Tested by the author on Windows desktop. Mobile/touch is unvalidated; recurrence and calendar-slot event creation are not included. See the README for setup and limitations.
